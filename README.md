# Forage India

Wild food across India by state and season: what grows near you this month, how to harvest it safely, the dangerous lookalikes to avoid, and a Forage to Table menu of dishes to cook with it.

**Live site:** enable GitHub Pages for this repository (Settings → Pages → Deploy from branch → `main` / root).

## Works offline
On first visit the site saves itself and all photos to the phone, so it keeps working without signal. On Android or iPhone, use the browser's *Add to Home screen* to install it like an app.

## Safety
This is a learning aid, not an identification authority. Never eat a wild plant on the strength of an app alone. Confirm every plant with an experienced local forager.
